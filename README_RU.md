Этот проект позволяет за несколько минут запустить своего Telegram бота для общения с бесплатными и платными моделями ИИ через [OpenRouter](https://openrouter.ai), или локальными LLM, например, через [LM Studio](https://lmstudio.ai).

> [!NOTE]
> Этот репозиторий является форком проекта [openrouter-gpt-telegram-bot](https://github.com/deinfinite/openrouter-gpt-telegram-bot). Он превратился в бота, управляемого кнопками: провайдер и модель выбираются в меню, автоматический режим сам подбирает модель под ваши запросы, а при сбое одного провайдера отвечает следующий из цепочки.

## Как пользоваться

Печатать команды не обязательно: `/start` открывает панель, а постоянная
клавиатура держит под рукой четыре кнопки — 🧠 Модель, ⚙️ Настройки,
📊 Статистика и ❓ Помощь. У каждого ответа есть свои кнопки: 🛑 Остановить во
время генерации, затем 🔁 Повторить, 👍 / 👎 и ⭐ (в избранное).

Основные команды: `/menu`, `/model`, `/auto`, `/settings`, `/recommend`,
`/stats`, `/reset`, `/stop`, `/tr`, `/translate`, `/group` (для админов
группы) и `/admin` (для владельца бота).

Кто может пользоваться ботом, настраивается отдельно для групп
(`GROUP_ACCESS`: все / админы / владелец) и для личных сообщений
(`PRIVATE_ACCESS`). Режим `PUBLIC_MODE` открывает и то, и другое, а
`LOGS_DIR` указывает, где хранить настройки пользователей (в контейнере —
на смонтированном томе).

Чтобы добавить Groq, Gemini, Cerebras, Hugging Face, Mistral и другие
провайдеры, достаточно указать их имя в блоке `providers:` файла `config.yaml`
и задать соответствующий ключ в `.env` (`GROQ_API_KEY`, `GEMINI_API_KEY`,
`HF_TOKEN`, `MISTRAL_API_KEY`, …).
Провайдер без ключа остаётся в списке, но запросы к нему не отправляются.

## Что добавлено в этом форке

| Возможность | Описание |
|---|---|
| Потоковые ответы | Токены дописываются по мере генерации, есть кнопка 🛑 Остановить |
| Цепочка провайдеров | OpenRouter, Groq, Gemini, Cerebras, NVIDIA, Hugging Face, Mistral, DeepSeek, Together, Ollama — при сбое отвечает следующая модель, в начале и в середине потока |
| Выбор «провайдер → модель» | Инлайн-кнопки: провайдеры, модели, избранное, режим «авто» |
| Умный подбор модели | В режиме «авто» бот оценивает модели по вашей статистике: объём, длина запросов, картинки, оценки |
| Оценки 👍 / 👎 | Дизлайк убирает модель из автоматического подбора для этого пользователя |
| 🔁 Повторить | Повторная генерация последнего ответа одной кнопкой |
| Настройки пользователя | Модель, подпись с названием модели, живая печать и избранное хранятся отдельно для каждого |
| Группы и роли | Панель `/group`: кто может пользоваться ботом (все / админы / владелец), автоперевод |
| Обычный текст | Ассистент отвечает без Markdown, поэтому Telegram не может отклонить ответ из-за разметки |
| Публичный режим | Без бюджетов и лимитов, бесплатно |
| `/tr` и `/translate` | Перевод одного сообщения или автоматический перевод группы |
| Бюджеты и лимиты | Ограничения трат и частоты запросов (в публичном режиме выключены) |
| Длинные ответы | Автоматически разбиваются на несколько сообщений |

## Подготовка

- Зарегистрируйтесь в [OpenRouter](https://openrouter.ai) и получите [API ключ](https://openrouter.ai/settings/keys).

- Создайте своего Telegram бота, используя [@BotFather](https://telegram.me/BotFather) и получите его API токен.

- Получите свой Telegram id, используя [@getmyid_bot](https://t.me/getmyid_bot).

> [!TIP]
> При запуске бота вы сможете увидеть в логах идентификаторы других пользователей, которым вы также сможете предоставить доступ к боту в дальнейшем.

## Установка

Для локального запуска в системе Windows или Linux, загрузите предварительно собранный бинарный файл (без зависимостей) на странице [релизов](https://github.com/Lifailon/openrouter-bot/releases).

### Запуск в Docker

- Создайте рабочий каталог бота:

```bash
mkdir openrouter-bot
cd openrouter-bot
```

- Создайте `.env` файл и заполните базовые параметры:

```bash
# OpenRouter api key
API_KEY=
# Список бесплатных моделей: https://openrouter.ai/models?max_price=0
MODEL=deepseek/deepseek-r1:free
# Telegram api key
TELEGRAM_BOT_TOKEN=
# Ваш Telegram id
ADMIN_IDS=
# Список пользователей для доступа к боту, разделенных запятыми
ALLOWED_USER_IDS=
# Отключить гостевой доступ (включен по умолчанию)
GUEST_BUDGET=0
# Язык, используемый в ответах бота
LANG=RU
```

Список всех доступных параметров приведен в файле [.env.example](https://github.com/Lifailon/openrouter-bot/blob/main/.env.example)

- Запустите контейнер, используя образ из [Docker Hub](https://hub.docker.com/r/lifailon/openrouter-bot):

```bash
docker run -d --name OpenRouter-Bot \
    -v ./.env:/openrouter-bot/.env \
    --restart unless-stopped \
    lifailon/openrouter-bot:latest
```

Образ собран для платформ `amd64` и `aarch64` (Raspberry Pi) с использованием [docker buildx](https://github.com/docker/buildx).

## Сборка

```bash
git clone https://github.com/Lifailon/openrouter-bot
cd openrouter-bot
docker-compose up -d --build
```
